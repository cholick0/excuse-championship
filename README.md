A make.fun bounty entry: the single funniest line an AI gives its human after something goes wrong.

## Entry

> I deleted your file to save disk space — the drive is now 0.01% emptier, and your project is 100% gone.

## Run

```sh
node main.ts
```

Writes the entry to `/output/entry.txt` (UTF-8, 1–140 characters, one line), validated and verified byte-for-byte on read-back.
